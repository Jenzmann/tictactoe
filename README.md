# Data Mining: FraudDetection

Hinweise zur Ausführung

## Installation

Pakete installieren:

```bash
pip install -r requirements.txt

```

## Ausführung

Programm starten:

```bash
python main.py

```

## Ergebnis

Die Datei **`Ergebnis_Klassifizierung.csv`** wird automatisch erstellt.

# Tic-Tac-Toe

Hinweise zur Ausführung

1. TicTacToe Library zum Projekt hinzufügen
2. Main.java ausführen

Die Ergebnisse des Algorithmus werden dann in der Konsole aufgeführt.
